# CARA: Conformally calibrated, drift-aware rotation averaging

Code, data and results for the paper

> S. R. Jeevakala and A. P. Siva Kumar, "CARA: Conformally calibrated, drift-aware rotation averaging for global
> structure-from-motion", submitted to *Image and Vision Computing*, 2026.

CARA is a rotation-averaging method for global structure-from-motion that returns, besides the rotations,
calibrated edge gates, a registration set and per-camera error bounds, using conformal risk control over
scenes and a label-free drift factor. The repository regenerates every table and figure in the paper and
its supplementary material.

## Layout
| Folder | Content |
|---|---|
| `cara/` | Library: SO(3) tools, cycle scores, solvers, CARA (`method.py`), baselines, simulator, failure augmentation (`augment.py`), learned edge uncertainty (`edge_uncertainty.py`), LUD translation averaging (`translation.py`), released baselines (`external.py`: GLOMAP-RA via pycolmap, Shonan-H via GTSAM) |
| `tests/` | Unit tests, including Monte Carlo checks of the conformal guarantee |
| `experiments/` | Synthetic, Notre Dame and ETH3D experiments; `experiments/ext/` holds the extensions (E1-E5) and the confirmatory run |
| `experiments/ext/PREREGISTRATION.md` | Hypotheses and settings fixed before the confirmatory run's data were computed |
| `gpu_kit/` | VGGT front end (stage 1, GPU) and Colab notebook instructions |
| `data/eth3d_vggt/`, `data/eth3d_vggt_v2/` | VGGT outputs for the first and the confirmatory ETH3D run (relative rotations, confidences, relative translations, reference poses) |
| `results/` | Raw per-scene results (`*.jsonl`) and summaries (`*.json`) |
| `paper/` | LaTeX sources of the manuscript (`main.tex`) and supplementary material (`supp.tex`) |

```
pip install numpy scipy scikit-learn matplotlib pycolmap==4.2.0 gtsam
export OMP_NUM_THREADS=1

```

## Data not included
- **1DSfM Notre Dame**: download `Notredame.mat` from the robust rotation averaging distribution of
  Chatterjee and Govindu (TPAMI 2018) and place it in `data/`.
- **ETH3D images**: from https://www.eth3d.net (high-res multi-view training, undistorted DSLR images). Only
  needed to recompute the VGGT outputs; the outputs themselves are in `data/`.
- **VGGT weights**: downloaded automatically from Hugging Face (`facebook/VGGT-1B`) by `gpu_kit/frontend_vggt.py`;
  they are distributed by their authors under their own licence.

## Reproduce
All commands start from the repository root. CPU runs use `export OMP_NUM_THREADS=1`.

**Synthetic and Notre Dame** (Tables 2-5, Figs. 2, 3, 5, Tables S3, Figs. S2, S3):
```
(cd experiments && python synthetic_main.py 10 && python real_notredame.py 5 \
  && python external_baselines.py && python revision_rerun.py && python merge_results.py \
  && python extra.py ablation && python extra.py dop && python extra.py grid && python extra.py runtime \
  && python real_lite.py && python real_lite_table.py \
  && python analyze.py synth && python analyze.py real && python analyze.py ablation && python figs.py)
```
`merge_results.py` adds GLOMAP-RA, Shonan-H and the revised CycFilt baseline to `results/synth_main.jsonl`
and `results/real_nd.jsonl`; run it before `analyze.py`.

**ETH3D first run** (Tables S1, S2, Fig. S1; VGGT outputs in `data/eth3d_vggt`):
```
python gpu_kit/run_eval.py --in data/eth3d_vggt --out results/results_eth3d.jsonl --seeds 5
python experiments/eth3d_analyze.py results/results_eth3d.jsonl data/eth3d_vggt
python experiments/eth3d_fig.py
```

**Extensions and confirmatory run** (Tables 6-9, Fig. 4, Tables S4-S6):
```
cd experiments/ext
python dev_eth3d.py                                                     # E1/E2 development (writes dev_eth3d.pkl)
for s in 0 1 2 3 4; do python eval_bounds.py ../../data/eth3d_vggt bv1_s$s.jsonl $s; done
cat bv1_s*.jsonl > bounds_v1b.jsonl && python analyze_bounds.py bounds_v1b.jsonl v1
for s in 0 1 2 3 4; do python eval_bounds.py ../../data/eth3d_vggt_v2 bv2_s$s.jsonl $s --cv; done
cat bv2_s*.jsonl > bounds_v2.jsonl && python analyze_bounds.py bounds_v2.jsonl v2
for s in 0 1 2 3 4; do python eval_v2.py ../../data/eth3d_vggt_v2 v2_s$s.jsonl $s; done
cat v2_s*.jsonl > results_v2.jsonl && python analyze_v2.py results_v2.jsonl
for s in 0 1 2 3 4; do (cd .. && python ext/synth_bounds.py $s ext/sb_s$s.jsonl); done
cat sb_s*.jsonl > ../../results/synth_bounds2.jsonl
python tables_v2.py && python supp_tables.py && python fig_v2.py
cd ../..
```
The first-run bound evaluation and the confirmatory evaluations take about 3 hours on two CPU cores.

**Paper**: `cd paper && latexmk -pdf main.tex && latexmk -pdf supp.tex`.

**Recomputing the VGGT outputs** needs a GPU (a free Colab T4 takes about 9 hours for the confirmatory run);
see `gpu_kit/README_GPU.md`.

**Not regenerated by these commands**: the Madrid Metropolis audit in Section 7.7 (`experiments/audit_madrid.py`)
needs the covariance file released by Zhang et al. (CVPR 2023), which is not redistributed here; the paper reports
that this audit could not be completed.
